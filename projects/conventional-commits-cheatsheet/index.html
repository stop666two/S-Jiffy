Conventional Commits 速查

Conventional Commits 规范类型表速查：搜索过滤、点击示例复制，附完整示例 commit。

类型含义示例（点击复制）

提交格式规则

<type>(<scope>): <subject> —— type 必填，scope（影响范围）可选，subject 用祈使句、小写开头、不超过 50 字符

破坏性变更：在 type 后加 !（如 feat!），或在 footer 中写明 BREAKING CHANGE: 描述

footer 用于附加说明：关联 issue（Refs #123）、协同作者（Co-authored-by: name <email>）等

每条 commit 只做一件事：一次提交只包含一个逻辑变更

完整示例 commit

feat(auth): add login page

Implement OAuth2 flow with refresh token support.

Refs #42

fix!: drop support for Node 14

BREAKING CHANGE: Node.js >= 16 is now required.

perf(api): cache user lookups

Reduce average latency by 30%.
