DNS 优选

实测各家公共 DNS 的解析延迟并给出最快的一项，附 DNS IP 与 DoH 地址；另可按域名对解析出的 IP 测握手耗时。

解析器 地区 延迟（中位） 状态 解析结果

延迟为浏览器内实测的 HTTP 往返时间（每家 5 次取中位数），只反映当前网络到该 DNS 服务商 DoH 接口的快慢，不等同于系统设置 DNS 后的解析速度。标有「仅延迟」的服务商不允许跨域读取响应，因此读不到解析结果。

IP 地址 握手耗时（中位） 状态

握手耗时是浏览器向该 IP 发起 HTTPS 请求时的 TCP+TLS 建连时间下界，不含页面内容；证书与域名不匹配时浏览器会在握手后立即失败，耗时仍可用于比较线路快慢。该值不代表下载速度。
