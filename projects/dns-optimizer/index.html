DNS 优选

多域名实测各家公共 DNS 的延迟与成功率，按「延迟 + 成功率」综合评分排序并给出 Top 3 推荐；另可按域名对解析出的 IP 测握手耗时。

    解析器 地区 平均延迟 成功率 评分 状态

    延迟为浏览器内实测的 HTTP 往返时间（多域名 × 每域名 2 次，取成功请求的平均值），只反映当前网络到该 DNS 服务商 DoH 接口的快慢。评分 =（1 / 平均延迟秒）× 成功率²，与开源项目 DNS Pick 同一思路：成功率取平方，避免「延迟低但常失败」的解析器排在最前。每家先做 1 次预热、连续 5 次失败即判定不可达并跳过剩余请求。标有「仅延迟」的服务商不允许跨域读取响应，因此读不到解析结果。

    IP 地址 握手耗时（中位） 状态

    握手耗时是浏览器向该 IP 发起 HTTPS 请求时的 TCP+TLS 建连时间下界，不含页面内容；证书与域名不匹配时浏览器会在握手后立即失败，耗时仍可用于比较线路快慢。该值不代表下载速度。
