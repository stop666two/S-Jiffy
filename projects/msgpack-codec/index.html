MessagePack 编解码

将 JSON 编码为 MessagePack 二进制（十六进制），或将 MessagePack 十六进制解码为 JSON。

编码：JSON → MessagePack
支持 nil / 布尔 / 整数（fixint、int8/16/32/64、uint8/16/32/64）/ 浮点（float64）/ 字符串（UTF-8）/ 数组 / 映射；16 位以上纯数字字符串按 int64 编码。
解码：MessagePack → JSON
解码支持 fixint / int8-64 / uint8-64 / float32-64 / str（fixstr、str8/16/32）/ array（fixarray、array16/32）/ map（fixmap、map16/32）；int64 / uint64 显示为字符串以避免精度丢失；bin / ext 类型暂不支持。
