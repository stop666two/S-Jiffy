视口尺寸工具

实时查看窗口、视口、屏幕与像素密度信息，窗口尺寸变化时自动更新。

说明
  • 窗口尺寸（outer）＝浏览器窗口整体大小；视口尺寸（inner）＝页面可用显示区域。
  • CSS 像素 = 视口尺寸；物理像素 = CSS 像素 × 设备像素比（DPR），即真实屏幕像素。
  • 滚动条宽度通过对比元素 clientWidth 与 offsetWidth 实测得出。
  • 设备分类按视口宽度推断：<600px 视为手机，600–1024px 视为平板，>1024px 视为桌面。
  • 颜色深度（bit）表示每个颜色通道的位数，通常为 24（真彩色）。
